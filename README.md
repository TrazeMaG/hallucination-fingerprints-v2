# Hallucination Fingerprints v2

> Causality, cross-model generalisation, and inference-time 
> intervention for LLM hallucination.

**Status:** In progress
**Author:** Nikhil Upadhyay
**Institution:** Independent Researcher, Dublin, Ireland
**v1 Paper:** https://doi.org/10.5281/zenodo.19934537

## What v2 proves

1. Last-Layer Suppression is causal — not correlational
2. The mechanism exists across model families and scales
3. It can be detected and corrected at inference time
4. Behavioural evidence exists in closed models (GPT-4, Claude)

## Models

Open source: GPT-2, GPT-2 Medium, GPT-2 Large, 
TinyLlama, Phi-3, Mistral 7B, LLaMA 3 8B

Closed (behavioural probing): GPT-4o, Claude 3.5 Sonnet
